# Issue #108 ランナー縦画面の再修正（v1.7.34）

基点: `5fe0a35`（PR #107マージ済みmain、v1.7.33）。専用ブランチ `fix/108-runner-portrait`。

## 原因と変更

- 正式画面のgridが余った高さをviewportへ配り、縦画面ではさらに18remの最低高を強制していた。16:9 Canvasの上下に余白が生じ、footerの説明文と42pxの非表示ステータス欄がボタンをさらに押し下げていた。
- 高さが足りなくなるとgridの最小必要高がiframeを超える。390×844のChromiumではdocumentスクロールは再現しなかったが、表示可能高を700pxに減らすとiframe内595pxに対しdocumentが656pxになり再現した。Safari実機の元の症状と同一原因と断定せず、実機で再確認する。
- 結果はviewport全体を基準に配置され、Canvasより高いパネル（クリア時276px）を許していた。`max-height`と`overflow:auto`も独立スクロールの原因になる設計だった。
- 正式画面を内容高で積み、viewportの16:9のセルと結果を同じgridセルへ重ねる。標準文字ではCanvas・結果の外寸を一致させる。文字拡大時は結果の必要高を優先しdocumentで読める。`overflow:hidden`による切り捨ては追加していない。
- DOM順をCanvas → ジャンプ → 開始/一時停止/再挑戦 → 説明 → 保存通知へ変更。非表示通知は`display:none`とし、通知が出てもCanvasと操作の位置は変わらない。
- 結果内のコース/キャラ、2種類の最高点、進行度の重複表示を削減。最高点詳細は既存の下部成績欄で確認できる。タイトル・今回の得点・保存状態・記録更新・次ステージ解放を表示。確定判定は従来どおり、保存完了レコードがありdirty/errorがない場合だけ。無料再開・再挑戦を維持。
- 両ゲームの上部ボタンを白背景・青文字/枠線・10px角丸・48px以上、「← 学習ホームへ戻る」に統一。ID、native button、フォーカス表示、navigateHome()は維持。
- ランナーに同じ`.section-kicker`で`WAKUWAKU RUNNER`を追加。共通の見出し前余白を調整。
- APP_VERSION、親のimport/iframe URL、子のCSS/JSとモジュールimportをv1.7.34へ統一。DB/backup v10、snapshot v2、課金・物理・アニメ素材・権限・プロフィール保存仕様は変更なし。
