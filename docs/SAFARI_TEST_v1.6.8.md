# v1.6.8 iPhone・iPad Safari実機確認手順（未実施）

Issue #13の公開前確認用。iPhoneのSafariとiPadのSafariで別々に実施し、端末・iOS/iPadOS・Safari版、日時、操作、期待値と実測値を記録する。Chromium自動テストの成功と実機確認を区別する。

## 準備

1. v1.6.7の完全バックアップを非公開の「ファイル」等に保管する。実際の履歴・バックアップ・教材データをGitHubやPRへ添付しない。
2. 本番とはデータが混ざらないテスト用端末・テスト用オリジンに、レビュー対象ブランチを配信する。本手順を作った作業では本番Pagesをデプロイしていない。復元・初期化は本番データでは行わない。
3. 教材と無関係な架空問題をE01とE04に用意する。単一/複数正解と改行入りの問題を含める。残高試験は架空データで100枚以上を用意する。保護者テストは無料なので、消費試験には学習用を使う。
4. 学習用・テスト用それぞれの残高、回答件数、初正解/初習得/復習報酬の件数、消費件数、景品数と7枠の配置を控える。必要ならMacのSafari WebインスペクタでIndexedDBを確認する。確認用の値だけを記録し、完全な保存データを公開しない。

## 履歴と問題の復元

1. 外部ページからゲームを開く。ホームでE01を選び、問題ID・選択肢順を控えて未回答の選択を行う。
2. Safariの戻るでホーム、進むで同じ問題・選択肢順へ復帰する。同一タブでは選択も維持される。5往復して履歴の段数が増えず、回答・報酬・消費の件数が変わらない。
3. iPhoneの左端からの戻るスワイプでも同じ確認を行う。スワイプ途中のキャンセル後に画面と選択が一致する。
4. 正解を確定し、正誤・正解・解説・今回のコイン表示を控える。戻る→進む・リロード後も同じ結果と報酬が表示され、回答・コイン記録が増えない。「次の問題」で通常どおり進む。
5. 次問に進んでから戻る→進むを行い、過去の問題ではなく現在のセッションに戻る。E04を新しく選んだ後も時代が混ざらない。
6. 問題画面の「ホームに戻る」は必ずゲームのホームに移動する。その後のブラウザ戻るは直前のアプリ画面に戻る。初期ホームからのブラウザ戻るは元の外部ページへ戻り、進むでゲームへ戻れる。
7. URLを直接開く場合、問題画面からのリロード、タブを閉じて開き直す場合でも安全に表示される。復元対象セッションがない履歴ではホームに戻り、復帰だけで抽選・報酬付与しない。

## 保存中の離脱とページライフサイクル

1. 正解直後に戻る／進む・ホーム操作・別アプリ切替を行う。保存が確定したら結果、確定しなければ未回答となり、別時代・別プロフィールへ結果が描かれない。
2. 未回答・結果画面それぞれで、外部ページへの移動と復帰、タブ切替、画面ロックと解除を試す。実際にbfcacheが使われたかは、可能ならWebインスペクタで`pageshow.persisted`を観測する。使われなかった場合は通常の再読み込みとして記録する。
3. Safari終了→再起動も試す。OSが保存途中のプロセスを終了した場合は、保存済みの状態と表示が一致し、未確定の回答に報酬が付いていない。未確定の選択のプロセス越え保持は必須にしない。
4. 容量不足や読込エラーを安全に再現できる環境があれば、古い残高を最新値として示さず「確認できません」等の案内が出ることを確認する。本番のサイトデータ削除で試さない。

## 複数タブとプロフィール

1. 学習用ホームをタブAで開き、タブBで学習用キャッチャーを1回購入する。Aに戻ると最新残高（100枚減少）となる。報酬記録は減らず、消費記録だけが1件増える。
2. 同じ問題を2タブで開き、一方で回答する。もう一方から同じ回答を確定しても回答・報酬が二重に増えず、最新の保存結果へ復帰する。
3. 管理→テストホーム→問題→結果→ホーム→キャッチャー、戻る・進む、管理→学習用ホームを試す。プロフィール表示・残高・履歴・景品が一致し、テスト操作が学習用へ保存されない。
4. 管理画面をリロードして管理画面に戻れる。問題編集後のダッシュボード再描画でも管理画面から移動せず、不要な履歴が増えない。

## キャッチャーとバックアップ

1. 学習用で1回購入してアーム移動中に戻る→進む、タブ切替、ページリロードを行う。戻っただけでは動かず、追加料金なしの再開ボタンを待つ。
2. キャッチ演出中に離れ、復帰後に保存済み結果を手動で再開する。結果が再抽選されず、課金は1回、獲得は最大1件。成功した枠だけが空になり、他の6枠は維持される。
3. テスト用でも同様に確認し、学習用残高や配置を変えない。価格・確率・操作・改行・iPhone/iPadの表示に回帰がない。
4. 架空データでv7を書き出し→プレビュー→復元→リロードし、両プロフィールの回答・結果・残高・景品・配置が一致する。プレビューだけでDBを変えない。旧v1〜v6も利用可能な架空データで確認する。

合否は「確認済み / 不合格 / 未確認」で残す。不合格時は端末・OS・操作列と件数・残高の差分だけを共有し、実データや教材を添付しない。Safari実機の合格前に、本修正が元の報告を解消したと断定しない。
