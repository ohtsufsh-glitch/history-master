# 歴史マスター v1.6.11：問題画面の所持コインとホームボタン

Issue #14。最新main `9503c33`（v1.6.10、Issue #12・#13・#15を含む）から `feat/quiz-coin-display` で実装。PRでレビューを待ち、mainへのマージ・GitHub Pagesへのデプロイは行わない。

## 表示と操作

- 問題画面 `#quiz` の上部に、左「🏠 ホームへ」、右「金貨画像＋所持 N枚」を横並びで表示する。ホームボタンは既存の `#back-home` と `navigateHome()` を再利用し、高さ48px以上、緑色の背景・枠・影を付ける。
- 所持枚数は3桁区切り。正常に取得した0枚は「所持 0枚」、取得中は「確認中…」、取得失敗は「確認できません」と表示する。長い枚数は右側の表示内で折り返す。
- 金貨は既存 `assets/coins/crown-gold.webp` を再利用。画像の追加・変更はない。残高は `role="status"` で読み上げ対象にする。
- 所持表示は問題画面専用。ホームの既存表示を維持し、共通ヘッダーへ追加しない。結果欄の「+N コイン獲得！」と獲得演出も維持する。

## 更新・保存・競合

`refreshCoinDisplay()` を拡張し、既存 `getAvailableCoins()` の結果からホームと問題画面を更新する。`coinEvents`・`reviewEvents`・`coinSpends` を同じreadonlyトランザクションで読む既存計算を維持し、新しい残高計算・正本キャッシュは追加しない。

再取得開始時と画面復元開始時には問題画面を「確認中…」へ切り替える。`viewContext()` / `viewCurrent()` の画面世代・プロフィールと `coinRender` の要求番号が一致する取得結果だけを反映する。古い成功・失敗で新しいプロフィールや新しい取得結果を上書きしない。取得失敗後も次の正常取得で表示が回復する。

問題初回表示、回答保存後、次の問題、別画面からの復帰は既存描画経路を使用する。履歴戻る/進む・リロード・bfcache・タブ復帰もIssue #13の既存処理を利用する。別ウインドウから問題画面へフォーカスが戻った場合にも残高だけを再取得する。

回答保存・報酬付与は既存トランザクションのまま。選択肢タップでは残高を変更せず、保存成功前・保存失敗時に未確定の報酬を加算しない。回答保存が成功しても残高の読み込みに失敗した場合は「確認できません」とし、保存済みの今回報酬は結果欄に維持する。

## 互換性

- **DB_VERSION=7 / BACKUP_VERSION=7 / IndexedDB全14ストア**を維持。新しいストア・保存フィールドは追加しない。問題JSON・旧バックアップ受理範囲・保存形式は変更しない。
- 初正解・初習得・復習報酬と2回連続正解の習得判定、キャッチャー料金・成功率・景品配置、シークレットの出現率・保存後公開、ぬいぐるみ拡大ポップアップを維持する。
- `navigateHome()` / History APIの既存連携を変更しない。ホーム操作は同じアプリ内へ移動し、同じホームへの繰り返し移動では履歴を増やさない。標準の戻る/進む、問題ID・選択肢順・回答結果の復元を維持する。
- 公開可能な架空データだけをテストに使用する。教材由来のJSON・実際の学習履歴・バックアップ・認証情報は追加しない。
