# Issue #81：衝突後の自動継続・残機ハート

## 対応仕様と変更ファイル

作業元は最新main `ae909668`（PR #80マージ済み）、専用ブランチは `issue-81-runner-auto-continue`。

- `runner/game.js`：障害物への接触で残機を1減らし、残機があれば`running`のまま、そのサブステップで`invincibleRemaining=1`を設定する。残りのサブステップも通常どおり進め、得点・取得済みスター・進行距離・ジャンプ・足場・出現順序を維持する。自動リトライや時間・距離の二重更新は行わない。
- 同じサブステップでの衝突を先に処理し、最終衝突だけがスター・ゴールより優先される。残機があれば無敵中のジャンプ・スター取得・ゴールを継続できる。無敵解除は最大1/120秒の判定猶予を含む約1秒。
- `resumeRunner`は一時停止からの手動再開専用。既存の回転・画面サイズ変更・visibilitychange・pagehide/pageshowで走行を中断し、復帰後も「再開」を待つ。無敵時間は走行のサブステップでだけ減り、中断中には減らない。再開時に描画時刻を初期化し、アプリ切替中などの実時間を消費しない。
- `runner/index.html` / `runner/style.css`：数字の残機HUD、衝突メッセージ、「つづける」画面、可視の「シールド・無敵中」を削除。既存Canvasシールドリングを使用する。ゲーム枠内左上に半透明のハートHUDを固定し、有効`♥`・喪失`♡`で塗りと輪郭を区別する。タップをCanvasへ通し、Safe Area対応済みのゲーム枠に収める。装飾は`aria-hidden`、状態は`role=status`・`aria-live=polite`・「残機3機中あと2機」のアクセシブル名を提供する。
- `runner/characters.js`：なまけもの2機、オオサンショウウオ3機に変更し、なまけものの古い「残機多め」表記を除去。オオサンショウウオの特徴は元の短い文を維持し、狭い横画面でも収める。しば犬・金魚は2機、走力・ジャンプ・画像は維持。
- `tests/runner_canvas_test.py` / `runner_preview_test.py` / `runner_stages_test.py` / `runner_characters_test.py` / `runner_character_ui_test.py`：新仕様の衝突・ハート・無敵・リトライと既存機能の回帰を検証。
- `docs/RUNNER_CHARACTERS.md`：現行能力表と衝突仕様を更新。PR #80当時の検証記録は履歴として区別。
- `index.html`：APP_VERSION `v1.7.20` → `v1.7.21`。ランナーHTMLのCSS/JSおよびJSのステージ/キャラクターモジュール配信識別子も`1.7.21`に統一。

通常URLは従来のしば犬固定コース、`/runner/?stagePreview=1`は4匹×6ステージの無料試遊を維持。ステージ難易度・配置・画像は変更しない。本体の学習・UFO・コイン・IndexedDB・バックアップ・課金・永続記録・シークレットは変更しない。本体コードの変更はAPP_VERSIONの1行だけで、データ構造・保存データへの影響はない。
