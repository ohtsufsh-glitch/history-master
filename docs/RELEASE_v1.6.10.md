# 歴史マスター v1.6.10：獲得済みぬいぐるみの拡大表示

Issue #15。最新main `fc2977b`（v1.6.9、Issue #12・#13マージ済み）から、`feat/plush-collection-popup` で実装する。PRでレビューを待ち、mainへのマージ・GitHub Pagesへのデプロイは行わない。

## 表示と操作

- 獲得済みの通常20種類・シークレット3種類のカードをbuttonにし、共通のネイティブdialogを開く。正式画像・名前・「獲得数：N体」と「× 閉じる」を表示する。
- 画像は既存 `assets/plush/{id}.webp` をそのまま使用。`object-fit:contain`、最大幅420px、高さは画面に合わせて縮める。画像ファイルの追加・変更はない。
- 背景はクリーム色〜淡い金色のCSSグラデーションと小さな星。角丸と影、短い表示アニメーションを使い、`prefers-reduced-motion` ではアニメーションを停止する。
- 閉じるボタン・外側タップ・Escapeで閉じる。内側の余白・画像や内側から外側へのドラッグでは閉じない。
- 開いたときは閉じるボタンへフォーカスを移し、閉じたら元のカードへ戻す。再描画で元のカードが消えた場合はコレクション見出しへ戻す。
- ネイティブmodalで背面の操作とフォーカス移動を防ぎ、bodyを固定して背面スクロールを止める。閉じたら元のスクロール位置を復元する。低い画面ではdialog内をスクロールでき、閉じるボタンは上端に固定される。

## 正体非公開・プロフィール・中断

`plushCollectionItem()` / `plushPresentation()` / 既存の獲得済み `data-prize-id` と両コレクション欄を再利用する。未獲得の通常は従来のグレー表示、秘密は共通「？」・「？？？」のまま。未獲得カードはbuttonにせず、正式IDの操作属性・秘密の名前を含むalt/aria-labelも付けない。

開く直前に現在のプロフィールの `arcadePrizes` と `arcadePlays` を読み直す。古いDOMや架空の操作属性だけでは開けない。非同期読み込み後にも画面世代・プロフィール・要求番号・元カードの存在を照合する。

アーム移動・結果処理・手動再開待ちを含む `aiming` / `resolving` の保存プレイがある場合、または `arcadeBusy` / バックアップ処理 / 初期化中は開かない。完了済みプレイを通常閲覧する場合は、手動再開フラグだけが残っていても開ける。既存の保存確定後のシークレット公開演出は変更しない。

画面遷移・student/test切り替え・履歴復帰・ページ非表示時には閉じる。復元・初期化後も既存の画面初期化経由で閉じる。閉じると画像src・alt・名前・個数を消去し、読み込み中の開く要求も無効にする。

## 保存・履歴との互換性

- **DB_VERSION=7 / BACKUP_VERSION=7 / IndexedDB全14ストア**を維持。DB名・保存フィールド・景品ID・バックアップ形式・旧版受理範囲は変更しない。
- ポップアップは読み取り専用。学習・回答・コイン・消費・景品・盤面・プレイの保存処理は変更しない。新しいストアや保存フィールドは追加しない。
- 開閉はHistory APIを呼ばず、履歴長・state・URLを変更しない。Issue #13の画面履歴処理に、閉じる呼び出しだけを追加する。
- Issue #12の抽選確率・運搬判定・保存・公開順序は保持する。Issue #14は対象外。
