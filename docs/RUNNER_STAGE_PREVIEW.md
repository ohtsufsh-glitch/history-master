# Issue #76：6ステージ無料試遊

## 入口と操作

- 通常の `/runner/` は従来の6400px固定コースを使用する。
- `/runner/?stagePreview=1` だけに「試遊モード・無料・記録されません」と選択欄を表示する。
- 初期選択はS01。S01〜S06をすべて選択できる。ステージ番号・名称・難易度・走行秒数・トゲ岩数・足場数は `runner/stages.js` の `STAGES` から生成する。
- 選んで「ゲーム開始」を押すと開始。「一時停止」「再開」を使える。走行中・一時停止中は選択できない。
- 終了後は「もう一度」で同じステージを最初から遊べる。別ステージを選ぶと開始前へ戻り、得点・進行度・物体・結果表示・アニメーション・描画時刻を初期化する。
- ステージ追加時は `STAGES` に定義を追加する。選択UIにID別の分岐や固定件数は設けない。

残機は今回の直接依頼に従って**1機・1回のトゲ岩接触でゲームオーバー**を維持する。
GitHub Issue #76/#74の追記には「2機・途中再開」とあるが、今回の依頼とは異なるため実装しない。
ジャンプ高さ120px・同じ高さへの滞空0.9秒、速度200px/秒、既存の足場・衝突・しば犬アニメーション・スター10点/最大100点を維持する。

## 変更範囲とデータ互換性

`runner/index.html`（選択UI）、`runner/game.js`（試遊判定・切替・復帰）、`runner/style.css`（縦横表示）、`tests/runner_preview_test.py`、本書、`index.html` のAPP_VERSION。
既存の `runner/stages.js` の距離と配置、ゲーム物理・衝突判定は変更しない。
APP_VERSIONは `v1.7.18` → `v1.7.19`。CSS・ゲームJS・ステージJSの配信識別子も `1.7.19` に揃える。
学習・ホーム・UFO・コイン・IndexedDB・バックアップの処理とデータ構造には変更しない。
ランナーは本体を読み込まず、IndexedDB/localStorage/sessionStorageにアクセスしない。試遊料金の消費もクリア記録の保存もない。

## 正式課金導入時の必須対応

`runner/game.js` 先頭の `STAGE_PREVIEW_ENABLED` を `false` にするか、この試遊入口を削除する。
`false` の場合は `stagePreview=1` でも通常コースになり、選択UIを表示しないことを自動テストで検証する。
このフラグは無料試遊の公開を止めるためのスイッチであり、有料プレイの認証ではない。
正式な50コイン課金時には通常入口も含めた権限検証を別途実装する。今回はその課金・保存処理を追加しない。

## iPhone/iPad Safari実機の確認項目

ドラフトPRのレビュー後、ユーザーによるマージ・配信を経て実機確認する。この作業では本番を更新しない。

- 通常URLで従来コース、試遊URLで無料表示とS01初期選択が出る。
- 縦横のネイティブ選択欄で6ステージを選べる。日本語の名前と難易度・時間・個数が読め、ボタンが重ならない。
- 各ステージの開始・ジャンプ・足場着地/再ジャンプ・落下・1回接触での終了・ゴールを確認する。
- 終了後の別ステージ選択で0点/0%に戻る。「もう一度」は同じコースで開始する。
- 走行中/一時停止中は選択不可。回転後も操作できる。
- アプリ切替・画面ロック・別ページへの移動と戻る/進むで自動走行せず、「再開」を待つ。開始前/終了後の復帰では選択可能。
- 60Hz/120Hz端末で操作感と難易度を比較する。
- 試遊の前後で本体の学習履歴・コイン残高・保存情報が変わらない。
