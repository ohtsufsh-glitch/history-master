# Issue #76：6ステージ無料試遊・残機2機と途中再開

> 本書はPR #78（v1.7.19）の記録。Issue #79（v1.7.20）で追加する通常4匹の選択・能力・キャラ別残機と最新の検証は [RUNNER_CHARACTERS.md](RUNNER_CHARACTERS.md) を参照する。通常URLの仕様は維持する。

## 入口と操作

- 通常の `/runner/` は従来の6400px固定コースを使用する。
- `/runner/?stagePreview=1` だけに「試遊モード・無料・記録されません」と選択欄を表示する。
- 初期選択はS01。S01〜S06をすべて選択できる。ステージ番号・名称・難易度・走行秒数・トゲ岩数・足場数は `runner/stages.js` の `STAGES` から生成する。
- 選んで「ゲーム開始」を押すと開始。「一時停止」「再開」を使え、1回目の衝突後は「つづける」で途中再開できる。走行中・一時停止中・衝突後の再開待ち中は選択できない。
- 終了後は「もう一度」で同じステージを最初から残機2機で遊べる。別ステージを選ぶと開始前へ戻り、残機・得点・進行度・物体・結果表示・アニメーション・描画時刻を初期化する。
- ステージ追加時は `STAGES` に定義を追加する。選択UIにID別の分岐や固定件数は設けない。

## 残機2機・同じ地点からの再開

Issue #76の確定仕様とレビュー指示に合わせ、通常コース・6ステージ試遊とも、各プレイの初期残機を**2機**とする。画面には「残り2機」のように数と言葉で表示する。

- 1回目のトゲ岩衝突で残機を1機減らして走行を停止し、「つづける」を表示する。ゲームオーバーにはしない。
- 「つづける」を押すまでは、進行距離・得点・取得済みスター・未取得オブジェクト・選択ステージ・ジャンプや足場の物理状態を保持する。
- 再開入力では位置を進めず、衝突地点から走行を再開する。再開直後の約1秒は無敵とし、同じトゲ岩との即再衝突を防ぐ。無敵状態はシールドなどの表示で分かるようにする。
- 無敵時間はゲームの進行時間にだけ連動する。一時停止・画面回転・アプリ切替・BFCache中は、走行と無敵時間を進めない。中断復帰時は自動走行せず、ユーザーの再開を待つ。
- 無敵終了後の2回目の衝突で残機0機・ゲームオーバーとなる。クリア・ゲームオーバー後の再挑戦は、同じコースの最初から残機2機に戻す。

ジャンプ高さ120px・同じ高さへの滞空0.9秒、速度200px/秒、既存の足場・衝突・しば犬アニメーション・スター10点/最大100点を維持する。

## 正式課金導入時の必須対応

`runner/game.js` 先頭の `STAGE_PREVIEW_ENABLED` を `false` にするか、この試遊入口を削除する。
`false` の場合は `stagePreview=1` でも通常コースになり、選択UIを表示しないことを自動テストで検証する。
このフラグは無料試遊の公開を止めるためのスイッチであり、有料プレイの認証ではない。
正式版30コイン課金時には通常入口も含めた権限検証を別途実装する。正式版は残機2機で1プレイ30コイン、1回目の「つづける」は追加料金なし、終了後の新規再挑戦は再課金という設計とする。今回はその課金・保存処理を追加しない。

## iPhone/iPad Safari実機の確認項目

ドラフトPRのレビュー後、ユーザーによるマージ・配信を経て実機確認する。この作業では本番を更新しない。

- 通常URLで従来コース、試遊URLで無料表示とS01初期選択が出る。
- 縦横のネイティブ選択欄で6ステージを選べる。日本語の名前と難易度・時間・個数が読め、ボタンが重ならない。
- 各ステージの開始・ジャンプ・足場着地/再ジャンプ・落下・ゴールを確認する。残機表示が狭い画面でも読める。
- 1回目の衝突で残り1機となって停止し、「つづける」で同じ地点・得点から復帰する。スターを二重取得せず、約1秒の無敵表示の間は同じトゲ岩で即死亡しない。2回目の衝突でゲームオーバーとなる。
- 終了後の別ステージ選択で残機2機・0点/0%に戻る。「もう一度」は同じコースの最初から残機2機で開始する。
- 走行中/一時停止中/衝突停止中は選択不可。回転後も操作でき、停止中に位置や無敵時間が進まない。
- アプリ切替・画面ロック・別ページへの移動と戻る/進むで自動走行せず、「再開」（衝突停止中は「つづける」）を待つ。開始前/終了後の復帰では選択可能。
- 60Hz/120Hz端末で操作感と難易度を比較する。
- 試遊の前後で本体の学習履歴・コイン残高・保存情報が変わらない。
