# v1.6.11 iPhone・iPad Safari実機確認手順

Issue #14。**実機確認は未実施**。レビュー用の安全な環境で、公開前に実施する。端末・OS/Safari版・縦横・文字サイズ・結果を記録する。Issue #12・#13・#15の既存確認手順も継続する。

## 準備

- iPhoneの375px・390px相当の縦幅、iPadの縦・横を使用する。通常と大きい文字設定、iPad分割表示、Safariツールバー表示/非表示も確認する。
- 実際の学習履歴を消去せず、架空問題と架空履歴のあるテスト端末を使用する。必要なバックアップは非公開で保存する。問題JSON・バックアップ・画面内の個人情報をGitHubへ登録しない。
- 保護者画面でアプリ版v1.6.11を確認する。studentとtestで異なる残高を用意する。コイン消費の試験にはテスト端末のstudentを使い、既存どおり100枚が必要なことに注意する。testのキャッチャーは無料のまま。
- 通常の0枚、1,000枚以上、回答で報酬が出る問題・出ない問題、2〜6択、長文と改行を含む架空問題を用意する。

## 配置・操作・読み上げ

1. 問題画面上部で左「🏠 ホームへ」、右「金貨＋所持 N枚」が横並びで見える。金貨画像が欠けず、数値は3桁区切り、0枚は「所持 0枚」になる。
2. 縦横回転・文字拡大・狭い分割表示でも、ホームの文字が読めて押せる。残高・問題文・選択肢・答え合わせ・次の問題が横にはみ出さず、2〜6択をスクロールして選べる。ホームの高さが44px以上ある。
3. 選択肢をタップしただけでは残高が増減しない。結果欄の「+N コイン獲得！」と上部の「所持 N枚」が別の意味だと読み取れる。
4. ホームへ移動すると、既存のホームの残高だけが表示される。共通ヘッダーにはコイン表示がない。
5. VoiceOverで「ホームへ」がボタンとして読める。所持残高・確認中・失敗の状態が読め、装飾の金貨画像を重複して読み上げない。外付けキーボードでもTab/Enterでホームへ移動できる。

## 保存・失敗・回復

1. 初めて正解し、回答保存後に上部の残高へ報酬が加わる。結果欄は「+N コイン獲得！」を表示する。保存前に獲得額が加わらない。
2. 2回連続正解の初習得、習得済みの復習、誤答、正解しても報酬0枚のケースを確認する。既存の報酬規則と習得判定が変わらない。
3. 「次の問題へ」で残高が保存済みの値と一致し、不要な履歴が増えない。同じ回答が再保存・二重付与されない。
4. テスト用のWeb Inspectorで一時的に残高読込を遅延させ、古い数値や仮の0枚ではなく「確認中…」になることを確認する。読込失敗時には「確認できません」、次の正常取得で残高が回復する。
5. テスト環境で回答保存を失敗させ、未確定の報酬が残高にも獲得表示にも加わらないことを確認する。再試行成功時に一度だけ加算される。保存成功後に残高読込だけ失敗した場合は、今回獲得表示を維持して所持表示だけ「確認できません」になる。

IndexedDBは端末内保存なので、機内モードだけでは保存失敗・読込失敗の再現にならない。失敗注入やデータ操作は架空データのある検証環境だけで行い、検証後はページを再読み込みして注入を解除する。

## 履歴・プロフィール・別タブ

1. Safariの戻る/進むボタンと画面端ジェスチャーで問題へ戻る。問題ID・選択肢順・選択途中・回答済み結果が既存どおり復元され、上部の残高が一致する。何度繰り返しても報酬・回答件数が増えない。
2. 回答済み・未回答でページを再読み込みし、保存された問題と残高が一致する。未保存の選択途中については既存仕様を維持する。
3. 別ページへ移動してから戻り、Safariのbfcacheから復帰する場合も最新の保存残高を読む。復帰だけでは採点・課金・獲得演出の保存処理を繰り返さない。
4. 外部ページからアプリを開いて問題へ進み、「🏠 ホームへ」を押す。外部ページへ突然移動せずアプリ内ホームになる。標準の戻る/進むは引き続き使える。同じホームへの操作を繰り返しても履歴を増やさない。
5. student/testを切り替え、それぞれの残高と結果になる。読込を遅延させた途中で切り替えても、古いプロフィールの残高が上書きしない。戻る/進むによるプロフィール復元も確認する。
6. 同じSafari・同じオリジンの別タブで回答してコインを増やし、元の問題画面へ戻ると反映される。別タブでキャッチャーを100枚で利用してから戻っても、消費後の残高になる。両タブで同じ回答を保存しても二重付与されない。
7. iPadの別ウインドウでコインを増減させ、元の問題画面へフォーカスを戻す。最新残高になる。アプリのバックグラウンド復帰でも確認する。
8. コインを増減しない表示更新・画面移動・ぬいぐるみ拡大の開閉だけでは、全14ストアの内容が変わらない。比較はテスト端末内で行い、比較用バックアップを公開しない。

## 既存機能の回帰

- キャッチャーの100枚消費、test無料、景品配置と入れ替え、成功/失敗、途中再開で追加課金なしを確認する。
- シークレットは未獲得時「？」のまま、保存成功後に従来の正体公開を行う。中断・再開で二重獲得しない。
- 獲得済みぬいぐるみの拡大、閉じる、画像/名前/個数、フォーカス復帰、未獲得保護を確認する。
- 旧バックアップ復元は架空データのテスト端末で行い、DB7・バックアップv7・14ストアの互換性を確認する。
