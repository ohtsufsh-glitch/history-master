# v1.6.10 iPhone・iPad Safari実機確認手順

Issue #15。**この実機確認は未実施**。mainへのマージ・Pagesへのデプロイ前に、レビュー用の安全な環境で実施する。端末・OS/Safari版・縦横・表示倍率・合否を記録する。v1.6.8の履歴管理、v1.6.9のシークレット確認手順も引き続き使用する。

## 準備

- iPhone（375/390px程度の縦幅）とiPadの縦・横で確認する。通常表示と文字を大きくした設定、「視差効果を減らす」を用意する。
- 通常・秘密を獲得したプロフィールと未獲得プロフィールを用意する。本番の学習データを初期化しない。復元・初期化は架空データのあるテスト端末だけで行い、必要なバックアップを端末外へ非公開保存する。
- 保護者用画面でアプリ版がv1.6.10であることを確認する。テスト用は無料、本番のプレイは既存どおり100金貨を消費するので、試験は原則テスト用で行う。

## 拡大表示・タッチ・見た目

1. 獲得済みの通常ぬいぐるみの画像とカードの余白をそれぞれタップする。中央のポップアップに正しい画像・正式名称・獲得数が出る。
2. 獲得済みシークレット3種類も同じポップアップで確認する。累計2体以上の景品も個数を照合する。
3. クリーム色〜金色の背景、控えめな星、名前・個数の読みやすさを確認する。画像が切れたり縦横に伸びたりしないこと、既存画像を拡大した画質を確認する。ぼやけが気になる種類は名前・端末を記録する。
4. 「× 閉じる」、外側タップで閉じる。閉じた直後のタップで背面のプレイ開始・景品入れ替えが実行されないことを確認する。画像・内部余白・画像から外側へのドラッグでは閉じない。
5. 開いた状態で背面がスクロールしないこと、閉じた後に元のコレクション位置へ戻ることを確認する。何度か開閉して、スクロール不能・画面の跳ね・タップ不能が残らない。
6. 開いたまま縦横を回転する。短い横画面、Safariツールバー表示/非表示、文字拡大、iPadの狭い分割表示でも横にはみ出さない。内部をスクロールしても閉じるボタンを押せる。
7. 「視差効果を減らす」設定ではポップアップ画像の表示アニメーションが止まり、閲覧と閉じる操作ができる。

## キーボード・VoiceOver

1. 外付けキーボードのTabで獲得済みカードへ移動する。Enter/Spaceで開き、閉じるボタンへフォーカスが移る。
2. 開いている間はTab/Shift+Tabで背面を操作できない。Escapeで閉じ、元のカードへ戻る。閉じるボタン・外側タップ後もフォーカスが戻る。
3. VoiceOverでカードに「名前を大きく見る、獲得数」の案内があること、dialogの名前・個数・閉じる操作が読めること、背面へ移動しないことを確認する。
4. 未獲得の通常は従来のグレー表示で開かない。未獲得シークレットは「？？？」だけで、正式画像・名前が画面にもVoiceOverにも出ない。

## プロフィール・履歴・保存・中断

1. 学習用で開閉してコイン・景品数・学習進捗が変わらない。テスト用へ切り替え、テスト用だけの画像と個数になることを確認する。学習用だけの秘密を開けない。
2. 開閉だけでSafariの履歴が増えない。開いたままSafariの戻る/進む（ボタンと端からのジェスチャー）で別画面へ移動すると閉じる。戻ってもポップアップが勝手に再表示されない。
3. タブ切り替え・バックグラウンド・別ページからのbfcache復帰・再読み込みで古いポップアップや秘密の名前が残らない。再度獲得済みカードを開ける。
4. アーム移動中・運搬中・結果保存/秘密公開中は獲得済みコレクションを押しても拡大しない。プレイ完了後は開ける。
5. 中断→戻る/進む・タブ復帰では手動再開待ちを維持し、待機中は拡大しない。再開で追加料金が発生しない。秘密は保存前「？」、保存成功後に既存どおり公開され、獲得が重複しない。
6. テスト環境でバックアップ復元・プロフィール初期化・完全初期化後に古いポップアップが残らず、再表示時に新しい獲得記録だけが使われることを確認する。公開後の本番端末で初期化を試さない。

自動テストでは全14ストアの開閉前後一致、History API非呼び出し・履歴長/state一致、通常20種・秘密3種、複数画面幅などをChromiumで検証する。SafariのOS動作・読み上げ・画質はこの実機手順で別途判断する。
