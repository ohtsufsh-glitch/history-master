# Issue #85 第2弾A：S04「空中の足場」

Refs #85。基点main `2c038b6`（PR #128マージ済み、v1.7.43）。S04だけを強化し、APP_VERSIONと親iframe・CSS・JSの配信識別子をv1.7.44へ同期。S05の上下移動・崩れる足場は次のPRへ分離する。

## コースと見た目

新規S04はstageVersion=2、7,000論理px、スター10個／最高100点。名称は維持する。キャラ性能・ハート・無敵1秒・操作ボタン・iframe高さ・Canvas比率は変更しない。

| 配置 | 論理座標 | 意図 |
|---|---|---|
| 足場 | X=2500〜3940、上面高さ100 | 手前からジャンプして着地し、その上で再ジャンプする |
| 地上壁 | X=2640〜3880、高さ90 | 地上走行で鳥の下を通る経路を阻止。幅1240は地上ジャンプ1回や無敵1回で越えられない |
| 鳥3羽 | 中心X=2880／3260／3640、中心Y=327（地上高143）、輪郭込み半径28 | 足場上のキャラ中心と同じ高さ。ジャンプで上を越える |
| トゲ岩 | 中心X=1600／5000 | 入り口・出口で基本ジャンプを確認 |

スターの(X, 地上からの高さ)：(1000,0)、(1600,120)、(2050,0)、(2580,100)、(2880,220)、(3260,220)、(3640,220)、(4450,0)、(5000,120)、(6500,0)。

鳥は濃い輪郭・赤い丸い体・目・眉・くちばし・羽を既存Canvas 2Dで描く。山や空と色・輪郭を分け、スターとも形を分ける。輪郭の外端と円形衝突判定が同じ半径28。内部の羽などは円内にclipし、羽ばたきで判定外へはみ出さない。判定はキャラ半径28との円同士。高度・世界Xは固定で、羽ばたきだけがゲーム内animationTimeで変わる。実時間・乱数・外部サービス・追加素材に依存しない。

鳥間隔は380px。しば犬では1.9秒、3ハートのオオサンショウウオでも約1.65秒。接触幅を含めても無敵1秒で次の鳥まで通過できない。足場上の再ジャンプをすべて省略すると2ハート・3ハートとも終了する。1回の上ジャンプだけでも、残る2羽でしば犬は終了する。一方、1回だけ操作を失敗してもハートを残してゴールすれば正式クリアとして扱う。

## 実入力の測定

しば犬（通常キャラ、200px/s、高さ120、滞空0.9秒、2ハート）へ開始とジャンプだけを入力。攻略中の座標補正・ハート変更・ゆにこの追加ジャンプは不使用。

| ゲーム内秒 | 操作 | 60Hzで単独入力をずらした連続成功幅 |
|---|---|---|
| 7.55 | 最初の岩を越える | ±0.167秒、幅0.333秒 |
| 12.00 | 足場へ登る | −0.233〜+0.500秒、幅0.733秒以上（探索上限） |
| 13.95 | 着地後、鳥1を越える | ±0.133秒、幅0.267秒 |
| 15.85 | 同じ足場へ再着地し、鳥2を越える | ±0.133秒、幅0.267秒 |
| 17.75 | 再着地し、鳥3を越える | ±0.133秒、幅0.267秒 |
| 24.55 | 後半の岩を越える | ±0.167秒、幅0.333秒 |

30/60/120Hzで全入力が受理され、足場着地と足場上からのジャンプ3回を確認。35秒／7000pxで100点・ハート2・被弾0。鳥全体が画面右端に入ってから各基準ジャンプ入力まで3.28秒あり、先読みできる。物理は既存の1/120秒以下のサブステップを使用。

実Canvas・RAF（時刻のみ制御）・pointerdownでもiPhone縦390×844／iPad横1024×768の両方で100点クリア。さらに正式なstudent30コイン購入画面でも、両サイズで既存ジャンプボタンのタッチハンドラーから100点・無傷クリアを確認した。

失敗経路：無操作、足場を除いた同じ入力、足場上の全ジャンプ省略、足場上ジャンプを1回だけ実施、はいずれもしば犬でゲームオーバー。オオサンショウウオが最初の岩を避けて足場へ登り、その後は走るだけの経路でも3羽でハート0。意図的に鳥1のジャンプだけ省いた経路は90点・ハート1で正式クリアし、過去100点を上書きしない。

S03の穴・足場間ジャンプの次に、同じ足場へ着地しながら敵を連続回避する段階にした。鳥回避の入力猶予はS03の足場間ジャンプ（約0.48秒）より短い。子どもの実操作による難易度評価はSafari実機で行う。

## 旧新版の保存互換性

DB v10・バックアップv10・snapshot v2・レコードschemaVersion=1を維持。変換・移行・削除・再購入強制はない。

- S04版1は6,400pxの旧定義をイベント順まで保持。S02/S03の版1・2、S01/S05/S06の版1もそのまま保持する。最新一覧のS04のみ版2へ置き換える。
- 購入時は最新定義のstageVersion、保存と復元は既存の`getStage(stageId,stageVersion)`を使用。親画面の`RUNNER_STAGE_VERSIONS`にもS04版2を追加する。
- 鳥は穴と同じくコース定義から再生成する。画面X=`186 + 鳥の世界X − snapshot.distance`、Y=`470 − height`。既存のdistance・animationTimeがそのまま位置と羽ばたきを復元する。
- 鳥をsnapshotのobjectsへ追加しないため、objectsの型・フィールド検証、旧版の構造・検証条件、snapshotの全キーは無変更。版1には鳥定義がなく、衝突も描画も増えない。
- v1.7.43の元コードから独立生成した公開可能な合成fixtureで、旧S04の購入直後・走行中・足場上の一時停止・足場から落下中・無敵中の5状態を保存／再開／再読込。6,400px・版1、次の軌道、他ストアを保持。
- 新版の成功・被弾経路の毎フレームで、snapshot復元後の次フレームが一致。鳥の座標・一時停止・羽ばたき用時間も一致する。正式購入では足場上・鳥越え中の保存／再開を確認し、ページ再読込後も版2・手動再開待ちになる。
- 旧S04/studentと新S04/testのactiveが混在するbackup v10をJSON往復・検証・一時DB復元し、全ストア完全一致と両コースの再開を確認。ファイル選択による既存バックアップUIの実復元は既存phase1/storageテストで検証。
- 料金student30／test0、プロフィール分離、確定結果・クリア履歴・解放・最高点は既存の仕組みを維持。未対応版は購入記録を保持して拒否する。
