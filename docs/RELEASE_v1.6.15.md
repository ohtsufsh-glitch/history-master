# v1.6.15 — ヘッダーのモード表示改善（Issue #25）

## 変更点
- 通常学習のモード表示アイコンを性別を限定しない「📖」に変更（ヘッダーの初期HTML・画面遷移時表示・問題画面 `#quiz-status` を統一）。
- 「🔧 保護者用」「🔧 テスト中」で薄黄色の背景の上に薄い文字が表示される問題を修正。`.mode-indicator.testtag` で背景 `#fef0d8`・濃色文字 `#704400` を明示し、後段のヘッダー一般色 `.mode-indicator` に上書きされないようにした。
- バッジには小さな角丸・内側余白・折り返し防止を設定。幅430px以下の既存「モード表示を隠す」挙動はそのまま。
- `.testtag` を使う問題画面の他要素には影響させず、ヘッダー内のバッジのみにスタイルを限定する。

## 互換性
- `APP_VERSION=v1.6.15` 以外に保存形式・学習機能の変更なし。
- `DB_VERSION=8`、15ストア、`BACKUP_VERSION=8`、問題・指摘JSONの形式を維持。
- 問題内容、回答履歴、コイン、カード、景品、プロフィール切替・管理画面、履歴ナビゲーションのロジックは未変更。

## PR #27の検証で見つかった不具合

幅431pxのテストモードで、バッジに追加した左右8pxの余白がタイトルの幅を圧迫し、「歴史マスター」の末尾だけが折り返していた。mainではヘッダー高74px・タイトル高36px、修正前PRではヘッダー高100px・タイトル高72pxとなることをChromiumで比較確認した。

バッジの左右余白を4pxへ縮め、背景・文字色・角丸・上下余白・折り返し防止を維持する。タイトルが1行に収まり、モード表示と重ならないことを既存テストの検査に追加する。修正後のヘッダー高74px・タイトル高36pxはmainと一致した。学習機能・データ形式は変更しない。
