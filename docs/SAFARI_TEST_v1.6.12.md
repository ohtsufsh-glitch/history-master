# v1.6.12 管理画面の階層化：Safari実機確認手順

**iPhone・iPad Safari実機は未検証。** 自動テストはChromiumで実施し、VoiceOver・Safariのファイル選択・履歴ジェスチャー・画面回転・文字拡大を実機確認済みとは扱わない。

このPRは未マージ・未デプロイ。公開前に、PRのソースをローカルHTTPサーバー等からテスト端末へ配信して確認する。実際の学習端末・教材データは使わず、架空の問題とテスト用バックアップを使う。バックアップは公開GitHubへ登録しない。

## 端末と初期表示

- iPhone縦375px・390px、iPad縦768px・横1024px相当で確認。OS・Safari版、端末、日時、結果を記録する。
- 保護者画面でv1.6.12、ホームへの戻りボタン、既存の説明文、「🔧 動作確認」とテスト開始ボタンを確認する。
- 「📚 問題を管理する」だけが開き、「💾 バックアップ・復元」「⚙️ その他の管理」が閉じている。下位パネルとカードプレビューはすべて閉じている。

## 上位・下位の開閉

1. 3つの上位タイトルをタップし、開閉できることを確認する。3つ同時に開いても互いを閉じない。
2. 問題管理内の下位ボタン4つを個別に開閉する。取り込み→一覧・修正・削除→マスター書き出し・更新→タグ設定の順である。
3. バックアップグループ内の下位ボタンから書き出し・復元欄へ進める。その他グループではカード画像確認→データ初期化の順で、完全初期化は末尾にある。
4. タイトル・ファイル入力・長いファイル名・ボタン・警告が画面内で折り返され、横スクロールが発生しない。開閉領域は押しやすく、意図しないスクロールやフォーカス移動がない。

## 入力・検査結果の保持

1. 問題一覧で検索・並び順・時代等を指定し、架空の取り込み問題の編集フォームに複数行を入力する。保存せず上位グループを閉じ、別グループも開閉し、元を開く。検索・並び順・フォームの入力が残る。
2. 新規取り込みファイルを選択し、検査結果を表示する。上位グループを閉じて開き、選択ファイル名・検査結果・保存ボタンを確認する。明示的に保存するまでは問題が増えない。
3. マスター書き出し→架空の解説だけを修正したファイルを選択→差分検査、タグ対応表の検査でも同様に保持を確認する。
4. バックアップ復元用ファイルを選択・検査し、上位グループを閉じて開く。検査結果・ファイル名が残り、復元前の警告が表示される。復元確認ダイアログでキャンセルすればデータが変わらない。
5. 初期化対象と確認チェックを選択し、上位グループを閉じて開く。チェック・対象件数・実行ボタンの状態が残る。確認チェックなしでは選択初期化を実行できず、確認ダイアログでキャンセルすればデータが変わらない。
6. 完全初期化では警告→確認ダイアログ→「初期化」の文字入力が必要。キャンセル・別の文字で実行されないことをテスト用環境で確認する。
7. 取り込み・復元・初期化の処理中にも上位グループを閉じて開く。処理が二重実行されず、再表示後に完了結果を確認できる。

既存の下位「問題一覧」自体を閉じる、編集をキャンセルする、保存する、ホームへのアプリ内ボタンで戻る、テストモードを開始する等による編集終了は従来仕様のまま。これらを上位開閉による消去と混同しない。リロード後の未保存入力の復元は今回追加していない。

## 履歴・表示・読み上げ

1. 上位・下位を何度も開閉してからSafariの戻るを実行し、メニューの開閉回数だけ履歴が増えていないことを確認する。進むで管理画面へ戻り、メニュー状態・選択ファイル・プレビュー・編集中フォームが残る。同じ文書へ戻る操作を対象とする。
2. 各パネルを開いたまま縦横回転する。Safariの文字拡大を通常・拡大で試し、タイトル・警告・入力欄を読め、操作できることを確認する。
3. VoiceOverを有効にし、上位タイトルの名前・開閉状態を読み上げること、ダブルタップで開閉できることを確認する。閉じたグループ内のボタンへ移動しないこと、開くと下位ボタンを順に操作できることを確認する。
4. キーボードを接続し、Tabで上位タイトル→下位ボタンへ移動、Enter/Spaceで開閉する。状態の読み上げと表示が一致し、操作対象へフォーカスが残る。
5. カードプレビューを開いて拡大し、閉じる。獲得状況・理解度・コイン・学習履歴が変わらない。

## テストモード開始・終了

1. 上位グループをすべて閉じても、動作確認のテスト開始ボタンを操作できる。
2. 確認後にテスト用ホームへ移動し、テスト表示、問題、無料クレーンへアクセスできる。
3. 管理画面へ戻り「娘さんの学習ホームに戻る」でstudentへ復帰する。studentの学習履歴・コイン・景品が変わっていない。
