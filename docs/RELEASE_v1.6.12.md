# 歴史マスター v1.6.12：保護者用管理画面の階層化

Issue #21。最新main `8b84bf6`（v1.6.11）から `feat/admin-menu-hierarchy` を作成。管理画面のレイアウトと開閉UIを変更し、PRでレビューを待つ。mainへのマージ・GitHub Pagesへのデプロイは行わない。

## UI構成

上部のホームへの戻り、管理画面の見出し、アプリ版、説明文を維持する。「🔧 動作確認」とテストモード開始は上位グループの外に置き、常時表示する。

| 上位グループ | 初期状態 | 下位の既存機能（表示順） |
|---|---|---|
| 📚 問題を管理する | 開く | 新規取り込み、一覧・修正・削除、問題マスター書き出し・一括更新、ジャンルタグ一括設定 |
| 💾 バックアップ・復元 | 閉じる | 既存のバックアップ・復元パネル |
| ⚙️ その他の管理 | 閉じる | 時代制覇カード画像確認、データ初期化 |

下位パネルはすべて初期状態で閉じる。上位は3つ、メニュー階層は最大2段。上位は同時に複数展開でき、互いを自動的に閉じない。Issue #20・#11の未実装機能や空ボタンは追加しない。

## 開閉と状態保持

上位はブラウザ標準の `details/summary` を使用し、既存DOMを内部に配置する。新IDは `admin-questions-group` / `admin-backup-group` / `admin-other-group` と、それぞれの内容領域。下位の既存ID、イベント登録、個別開閉を維持する。

上位開閉の独自イベントや再描画は追加しない。問題編集、検索・並び順、選択ファイル、取り込み・マスター更新・タグ設定・復元の検査結果、初期化対象と確認チェックが残る。処理中に上位を閉じても既存の処理フラグ・ボタン無効化・確認手順を維持する。同じ文書内のSafari戻る/進むに相当する画面復帰でもDOMの状態を保持する。

既存の下位一覧パネルを閉じる操作、編集キャンセル・保存、アプリ内ホーム復帰・テスト開始など、従来の編集終了操作は変更しない。データ更新による検査結果の無効化も従来どおり。リロード後の未保存入力の復元機能は追加していない。

## アクセシビリティ・レイアウト

- 上位タイトルに短い補足を付け、管理画面h2→上位h3→下位パネルh4→完全初期化h5とする。
- 上位の開閉状態はネイティブのアクセシビリティ情報で公開する。手動の `aria-expanded` を重ねず、Tab・Enter・Spaceによる標準操作を使う。下位ボタンは従来の `aria-expanded` を維持し、対応パネルへの `aria-controls` を追加する。
- 上位・下位の開閉領域は44px以上。キーボード用フォーカス枠を設け、開閉時に独自のフォーカス移動を行わない。
- 管理画面の折り返し・ファイル入力の最小幅を調整。画面遷移、開閉履歴の保存、アニメーション、外部依存は追加しない。

## データ互換性と既存機能への影響

**DB_VERSION=7 / BACKUP_VERSION=7 / IndexedDB全14ストアを維持。保存処理は未変更。** 問題JSON、採点・2回連続正解の習得、コイン規則、student/test分離、問題編集・削除・復元、マスター更新・baseRevision/baseHash検証、バックアップ復元互換性、カード獲得、クレーン・ぬいぐるみ、Safari履歴管理は変更しない。

mainとJavaScript全文を照合し、変更がアプリ版、編集フォーム見出しのHTMLタグ、トグル表示文言だけであることを確認した。既存DOM IDを全件維持し、重複がないことを確認。既存テストの全assertも版番号の期待値以外は一致する。

公開するテストには架空データだけを使う。教材由来の問題JSON、実際の学習履歴、バックアップファイル、認証情報は追加しない。テスト用ダウンロードは一時ブラウザの領域だけに作成する。
