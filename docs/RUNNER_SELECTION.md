# Issue #82 ランナーの選択UI（v1.7.30）

PR #100マージ後のmain（e3b8259、v1.7.29）から実装。

## 表示と操作

- 正式版のゲーム・操作ボタン下に、S01〜S06とキャラクターのボタンカードを配置。iPhone縦は2列、広い画面は3列。最高得点はその下の既存欄を利用。
- 選択状態は太枠・背景・「✓ 選択中」とaria-pressedで表示。ロックはdisabled・鍵・理由を表示。フォーカス枠と44px以上の領域を維持。
- 通常4匹の既存ぬいぐるみ静止画像を使用。画像と能力はcharacters.jsのIDに対応。selection.jsとselection.cssを正式版／試遊で共用。
- 既存selectはhiddenの選択状態保持用として残す。画面と読み上げの操作はネイティブbuttonへ集約。カードDOMは更新時も再利用し、フォーカスを維持。
- 走力／ジャンプの分類はcharacters.jsのabilityに集約。しば犬＝中／中、なまけもの＝低／中、金魚＝中／高、オオサンショウウオ＝高／低。
- ゆにこは実数値200px/秒・120pxがしば犬と同じなので中／中。ハート3個・空中追加ジャンプ1回。物理値は変更なし。
- ハート表記と読み上げを統一。選択変更で能力・初期ハート・キャラクター別最高点の強調も更新。

## 保存・秘密情報の境界

- 正式版は既存runnerLobbyDataのプロフィール別IndexedDB所持判定を利用。35種類での抽選解放だけでは選択不可。未獲得枠は「？？？」だけで、名前・画像・能力・個別最高点を含めない。
- プロフィール変更・復元・初期化・画面復帰の既存再照合を維持。カードも最新の所持／解放状態で更新。
- 開始前・正式終了の保存確定後だけ変更可能。走行、一時停止、購入済み中断、結果保存待ち、保存失敗、再開不能では固定。イベントハンドラ側でもID／解放／状態を検証。
- 終了直後の描画や遅延呼出で追加のadvance保存が走らないよう、bridgeは走行中だけadvanceを受け付ける。
- 料金は既存開始ボタンの購入処理のみ。選択操作は課金しない。ステージ解放・成績集計・再開・snapshot v2・DB／バックアップv10を維持。ストア追加なし。
- コース配置、ゲーム物理、教材、UFO課金・景品ロジック、画像・アニメーション素材は変更なし。
